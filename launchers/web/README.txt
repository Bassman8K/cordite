CORDITE web build
=================

This folder is the whole game. Browsers will not run it straight from the
file system, so it has to be served. The scripts here do that on your own
machine and open the game for you:

  macOS     double-click Play-Cordite.command
  Windows   double-click Play-Cordite.bat
  Linux     ./play-cordite.sh

They need Python 3 or Node.js, and use http://127.0.0.1:4173/.

To host it yourself, upload the folder to any static web server.
